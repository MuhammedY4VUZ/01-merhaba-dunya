# DOT311 — Hafta 1: Mobil Geliştirmeye Giriş ve Kurulum

Bu proje, DOT311 dersinin 1. haftasında öğrenilen Expo ve React Native kurulumunu ve "Merhaba Dünya" başlangıç ekranını içerir.

## Özellikler
- Expo SDK 52 / 58 ile managed workflow
- View, Text, StyleSheet kullanımı
- Fast Refresh ve etkileşim testi

## WebStorm'da Çalıştırma ve Expo Go Testi
1. WebStorm'da bu klasörü (`01-merhaba-dunya`) açın veya terminali açın.
2. Terminalde şu komutu çalıştırın:
   ```bash
   npx expo start
   ```
3. Ekrana gelen QR kodu telefonunuzdaki **Expo Go** uygulaması ile tarayın.
